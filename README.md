# Emberpvp Launcher — Windows 11 x64

Independent GPL-3.0-only Prism Launcher fork, restricted to Minecraft Java 1.21.11 + Fabric.

The Windows workflow reconstructs the complete corresponding source from `payload/*.b64`, verifies its SHA256, builds on Windows, runs tests, and packages a per-user installer and portable ZIP. Download successful build artifacts from Actions. Matching source and notices are included in both packages. No personal launcher data is included.

Extract the source archive to read `packaging/windows/WINDOWS-BUILD.md` for local Windows build instructions. The original Linux installation is independent.
