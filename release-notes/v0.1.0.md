# Emberpvp Launcher 0.1.0 — Windows x64

**Minecraft Java 1.21.11 + Fabric only.** Includes the Emberpvp interface, 3D player preview, mod and instance management, performance presets, and fictional prelaunch animation.

## Download and run

Download **EmberpvpLauncher-Windows11-x64-Setup.exe** below and run it on Windows 11 x64. The installer includes the required runtime libraries and installs for your current user. No development tools or GitHub account are needed to download or install it.

For a portable installation, download **EmberpvpLauncher-Windows11-x64.zip**, extract the entire ZIP, and run `emberpvp-launcher.exe` inside it. Keep the DLLs and folders alongside the executable.

## Included files

- Windows installer (`.exe`)
- Portable Windows ZIP
- Matching complete source archive and build instructions
- `SHA256SUMS.txt` for verification

This is an independent GPL-3.0-only Prism Launcher fork. Original notices and matching source are included in both binary packages; redistribute them with redistributed binaries. No personal accounts, tokens, worlds, or settings are included.

## Verification and requirements

Passed 34 test suites, the 3D skin-renderer test, portable native-window startup on a fresh Windows runner, and installer/uninstaller checks including preservation of user-added files. The build/test host was Windows Server 2022. Microsoft sign-in and actual Minecraft gameplay on a physical Windows 11 PC have not been independently tested.

These executables are unsigned. Use your own legitimate Minecraft account; Microsoft authentication and ownership verification remain in place. CurseForge requires an application API key; Modrinth does not. Performance presets check mod compatibility; no specific FPS improvement is promised. Compositor blur depends on platform support.

The prelaunch verification is a fictional visual effect. It does not collect real root passwords or banking/payment credentials, and makes no payments.
